# azplex - VS Code Extension

MCP server for Azure, Microsoft Fabric, and Azure DevOps.

## Prerequisites

Install the `azplex` pip package:

```bash
pip install azplex
```

## Usage

Once installed, the extension registers the `azplex` MCP server with VS Code. It's available to GitHub Copilot Chat and any MCP-compatible client.

## Features

- Azure resource deployment via Bicep templates
- Azure RBAC and PIM management
- Microsoft Fabric workspace and pipeline management
- Azure DevOps project, repo, and pipeline management
- Network Security Perimeter and compliance orchestration
